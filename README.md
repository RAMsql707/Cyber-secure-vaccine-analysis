# Cyber-secure-vaccine-analysis
Is project mein maine duniya bhar ke vaccine data ko analyze kiya hai aur ye dikhaya hai ki SQL Queries ka use karke hum Data Security aur Anomalies (galat data) kaise pakad sakte hain.
​Ethical Hacking Perspective
​Maine isme 3 security concepts apply kiye hain:
​Data Integrity: Queries ko aise likha hai ki wo sirf valid data hi uthayein.
​Anomaly Detection: CASE statement ka use karke abnormal spikes ko "Suspicious" mark kiya hai.
​Data Masking: SUBSTR function se sensitive information (Country names) ko protect kiya hai taaki privacy bani rahe.
​📈 SQL Skills
​Window Functions: DENSE_RANK()
​String Manipulation: SUBSTR, || (Concatenation)
​Conditional Logic: CASE WHEN
